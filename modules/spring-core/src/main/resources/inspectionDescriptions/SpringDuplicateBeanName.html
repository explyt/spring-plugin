Reports a @Bean method whose bean name is already declared by a differently named @Bean method of the same configuration class.

Spring Boot disallows bean definition overriding by default, so such a configuration fails at startup with BeanDefinitionOverrideException. Overloaded @Bean methods with the same method name are merged by Spring and are not reported. Nothing is reported when spring.main.allow-bean-definition-overriding=true is set in the module configuration.
