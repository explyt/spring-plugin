Reports a single environment-variable placeholder whose name repeats the relaxed-binding environment form of the full property key. For ordinary configuration keys, Spring Boot can read that environment variable without the placeholder.

Bootstrap and profile-selection keys are excluded: spring.config.import, spring.config.activate.on-profile, spring.config.location, spring.config.additional-location, spring.config.name, spring.profiles.active, spring.profiles.include and spring.profiles.group (including its entries).

The quick fix replaces the placeholder with a simple literal default and is available in Code Cleanup. No fix is offered without a default, with a nested placeholder or SpEL expression such as #{null}, with backslashes in a .properties default, or when a YAML default is not a simple plain value. The YAML check is conservative: quoted defaults and YAML-special scalars such as yes or 0x10 are left unchanged.

Limitations:

  • A JVM system property with the same name as the environment variable (for example -DEXPLYT_VALUE=override) can override the environment variable when resolving an explicit placeholder. Removing the placeholder may bypass that override.
  • The inspection checks any YAML or properties file that the plugin recognizes as Spring configuration, including files under config/ that Spring Boot does not load by default.
