Reports Spring Boot's @MockBean / @SpyBean test annotations, which are deprecated since Spring Boot 3.4 and removed in Spring Boot 4.0, and offers a quick-fix that replaces them with Spring Framework's @MockitoBean / @MockitoSpyBean (updating the import).

Runs from Spring Boot 3.4, the version that ships the replacements (Spring Framework 6.2) and deprecates the legacy annotations. While they are still on the classpath the problem is reported as a weak warning, because the IDE already highlights the deprecation itself; what this inspection adds there is the name of the replacement and the quick-fix. After the Spring Boot 4 removal nothing else reports the stale source, so the full warning applies.

Example:


// before
import org.springframework.boot.test.mock.mockito.MockBean;

@MockBean
private UserService userService;

// after
import org.springframework.test.context.bean.override.mockito.MockitoBean;

@MockitoBean
private UserService userService;

See the Spring Boot 4.0 Migration Guide.
