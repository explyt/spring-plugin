Reports an Actuator endpoint extended by more than one @EndpointWebExtension bean. Spring Boot fails the application at startup with Found multiple extensions for the endpoint bean.

The failure happens only for an endpoint exposed over HTTP through management.endpoints.web.exposure.include and exclude: an unexposed endpoint is never converted, so its extensions are not compared. management.endpoint.<id>.access=none and enabled=false do not prevent the failure.

Only extension beans count: a class without a bean definition, an extension whose bean condition does not match, and an extension in test sources of a production endpoint are ignored. A bean subclass of an extension bean is a second extension: the problem is reported on the extension annotation of the base class.

The problem is an error when the endpoint is exposed and at least two of its extension beans are registered whatever their bean conditions decide, and a warning when the exposure cannot be decided from the project configuration or fewer than two extension beans are certain to be registered.

Example:


    @Component
    @EndpointWebExtension(endpoint = StatusEndpoint.class)
    class StatusWebExtension {
    }

    @Component
    @EndpointWebExtension(endpoint = StatusEndpoint.class)
    class DetailedStatusWebExtension {
    }
